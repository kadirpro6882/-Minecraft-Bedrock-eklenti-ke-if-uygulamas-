# Blok Rehberi

Minecraft Bedrock eklentilerini kategorilere göre keşfet.

Silah, mobilya, aksiyon, moblar, araçlar, yapı ve diğer kategorilerinde ara; ilgini çekenleri favorilerine ekle.

Liste yaklaşık 5 saatte bir yenilenir. Sürüm uyumluluğu bilgileri eklentinin kaynak sayfasına dayanır; her eklenti ayrıca test edilmiş olmayabilir.

APK yayımlandığında GitHub deposunun **Releases** bölümünde bulunacaktır.
